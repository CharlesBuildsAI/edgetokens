Set it up.

  1. Flash Raspberry Pi OS (64-bit) to the microSD card with Raspberry Pi Imager. Raspberry Pi Imager ↗
  2. Fit the Active Cooler and plug in the 27W supply. Boot, connect to your network and update: sudo apt update && sudo apt full-upgrade
  3. Install Ollama with its official Linux script: 
    curl -fsSL https://ollama.com/install.sh | sh
    Ollama Linux install ↗
  4. Run a small model first. 
    ollama run llama3.2:1b --verbose
    --verbose prints the eval rate after each answer: that is your generation speed in tokens/sec.
  5. Share your number. Your run is exactly the kind of data this site is built on. Submit it here ›

What speed to expect.

  • 1–2B models: best sourced runs of 11.22 tok/s on Llama 3.2 1B (source ↗) and 11.73 tok/s on Qwen2.5 1.5B (source ↗). That is usable chat speed.
  • 3B models: 5.95 tok/s best on Llama 3.2 3B (source ↗). Usable, but slower than you read.
  • 8B models: 2.05 tok/s best on Llama 3.1 8B (source ↗). Jeff Geerling measured 2.05 tok/s on the 16GB board, 1.99 tok/s on the 8GB board, so 16GB buys room for bigger models rather than speed.
  • Results vary a lot by setup. One paper measured under 1 tok/s on the same models (see the full table below), so check the source before you compare.
