Jetson Orin Nano Super for local LLMs.

Same board, a free software update, and a lot more speed. Here is what Super mode changes, what to buy, and how to start.

Set it up.

  1. Flash JetPack to a 64GB+ microSD card (or an NVMe SSD) using NVIDIA's quick start guide. Super mode arrived with JetPack 6.2. NVIDIA quick start ↗
  2. Switch to the Super power mode (MAXN SUPER) described in NVIDIA's announcement. NVIDIA blog ↗
  3. Pick a runtime. NVIDIA's fastest numbers use MLC. Ollama is the easiest start and its Linux script supports Jetson: 
    curl -fsSL https://ollama.com/install.sh | sh
    Ollama Linux install ↗
  4. Measure and share. ollama run llama3.2:3b --verbose prints the eval rate. Submit your run ›
